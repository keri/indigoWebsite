## Recommended image specs

| Usage | Width | Format |
|---|---|---|
| Hero background | 2400px+ | JPG (quality 85) |
| Store product shots | 1600px | JPG (quality 90) |
| Portfolio items | 1200–1600px | JPG (quality 85) |
| Artist portrait | 1200px | JPG |

Use Squoosh or ImageOptim before uploading to keep file sizes reasonable.
